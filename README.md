# 📚 BookFlow — Library Management System

A full-stack library management system with a **Spring Boot** backend and a **React** frontend. It supports student and book management, book issuing/returning, JWT-based authentication, email verification, and reporting with charts.

---

## 🏗️ Tech Stack

| Layer | Technology |
|-------|-----------|
| **Frontend** | React 19, React Router v7, Vite, Bootstrap 5, Chart.js |
| **Backend** | Spring Boot 4.1, Spring Security, Spring Data JPA, JWT (jjwt) |
| **Database** | MySQL 8+ |
| **Auth** | JWT + Email verification (Gmail SMTP) |

---

## ✨ Features

- **Authentication** — Register, login, forgot password with email verification codes
- **Dashboard** — Overview with charts and statistics
- **Book Management** — Add, edit, delete, and search books
- **Student Management** — Add, edit, delete, and search students
- **Issue & Return** — Issue books to students and track returns
- **Reports** — Visual reports powered by Chart.js
- **Profile** — User profile management
- **Protected Routes** — JWT-protected dashboard with route guards
- **Notifications** — Toast and notification panel system

## 🚀 Getting Started

### Prerequisites

- **Java 21+**
- **Node.js 18+** and npm
- **MySQL 8+**

### 1. Database Setup

Create the MySQL database:

```sql
CREATE DATABASE librarymngdb;
```

Update `backend/LibraryManagementSystemAp/src/main/resources/application.properties` with your MySQL credentials:

```properties
spring.datasource.url=jdbc:mysql://localhost:3306/librarymngdb
spring.datasource.username=your_username
spring.datasource.password=your_password
```

The schema is auto-generated by Hibernate (`spring.jpa.hibernate.ddl-auto=update`).

### 2. Email Configuration (Optional)

For email verification, configure Gmail SMTP in `application.properties`:

```properties
spring.mail.username=your_gmail@gmail.com
spring.mail.password=your_app_password
```

> Generate an App Password at [myaccount.google.com/apppasswords](https://myaccount.google.com/apppasswords) (requires 2FA).

If left empty, verification codes will be logged to the console for development.

### 3. Backend

Using Maven:

```bash
cd backend/LibraryManagementSystemAp
./mvnw spring-boot:run
```

The API will start on **http://localhost:8081**.

### 4. Frontend

```bash
cd frontend/librarymngSystem
npm install
npm run dev
```

The frontend will start on **http://localhost:5173**.

## 📡 API Overview

The backend exposes REST endpoints under `http://localhost:8081`:

| Module | Endpoints |
|--------|-----------|
| **Auth** | `POST /api/users/register`, `POST /api/users/login`, `POST /api/users/forgot-password`, `POST /api/users/verify-code` |
| **Books** | CRUD via `BookController` |
| **Students** | CRUD via `StudentController` |
| **Issues** | Issue & return via `IssueBookController` |
| **Reports** | `ReportController` |
| **Dashboard** | `DashboardController` |

All protected endpoints require a `Bearer` JWT token in the `Authorization` header.
